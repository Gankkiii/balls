# Smooth Arena — 光滑竞技场

Godot **4.6.3 stable** / GDScript。仅一个竞技场、两个小球和 **1× / 2× / Pause** 三个按钮。没有技能、伤害、胜负、重置或调参功能。启动时暂停。

## 运行

1. 下载 Godot 4.6.3 普通版，无需 .NET。
2. 导入 `project.godot`，按 F5 运行。
3. 点击 1× 或 2× 开始；Pause 暂停。暂停后点击倍率继续，不重新随机。

## 结构

- `scenes/arena.tscn` + `scripts/arena.gd`：`class_name Arena`，负责边界、注册小球、统一模拟及碰撞处理。
- `scenes/ball.tscn` + `scripts/ball.gd`：`class_name Ball`，保存位置、速度、半径、质量、颜色，负责绘制和碰撞信号。
- `scenes/main.tscn` + `scripts/main.gd`：实例化一个 Arena 和两个 Ball、三个按钮以及固定时间步控制。
- `tests/run_tests.gd`：直接测试实际 Arena、Ball 和主场景控制逻辑，不使用一份独立的模拟替身。

Ball 的 `position` 是唯一权威位置；没有额外刚体引擎同时更新它。Arena 内的坐标使用逻辑像素，时间单位为秒。默认场地 640×680、球半径 24、质量 1、初始速率 140–230。初始化两个球使用分离的横向区域避免重叠。

修改默认参数可在 Arena、Ball 场景的导出属性中进行。当前初始化专门面向两个小球，若扩展更多球，需先改为通用无重叠布局并补测试。不要认为当前初始化天然适合任意数量或超大半径。

## 物理

- 无重力、摩擦和阻尼。完全弹性碰撞。
- 每个物理步为 1/120 秒。渲染回调累积真实时间，倍率决定推进多少个相同步长；切换倍率不会修改速度向量。
- 墙面反转法向速度分量；球间按逆质量计算弹性冲量，切向分量保留。
- 解析计算墙和圆的最早碰撞时间，在时间步内推进到碰撞点，响应后继续消耗剩余时间（连续碰撞检测）。
- 同一时刻的墙接触一起处理；球冲量仅在相互接近时施加。
- 数值重叠按逆质量分离，不通过归一化或加速掩盖误差。
- 每子步最多处理 128 次碰撞；达到上限明确报错并丢弃剩余子步，不把球推进墙外。正常范围及已测高速未触发。
- 碰固定墙不保持两球系统总动量。两球相撞保持总动量和总动能，但单球速率可以变化。
- 本项目是浮点数模拟，不承诺跨版本、跨 CPU 位级一致，也不是支持任意拥挤多体系统的通用物理引擎。

## 暂停、显示和后台

暂停只停止模拟，不暂停按钮。收到应用失焦或挂起通知后不累积时间。渲染回调最多接收 0.1 秒，长卡顿丢弃额外时间而不是突然补算。严重卡顿时不保证与墙上时钟严格同步。

固定 720×1000 设计尺寸，保持比例缩放，窄屏或宽屏留边。Android 锁定竖屏，按钮支持鼠标与触屏。文字使用内置字体与简短英文以避免依赖外部字体。

## 扩展约定

可以继承 Ball 增加显示、状态或组件，通过 `wall_collided(normal)`、`ball_collided(other)` 处理附加效果。普通碰撞信号不会造成伤害。若技能要改变速度，应作为明确规则修改，而非另启动一套位置更新循环。

可继承 Arena 或扩展其规则接口。多球、非圆形障碍、不同大小角色等需要单独验收，不在当前版本保证范围内。不要因为未来功能而移除基础回归测试。

## 自动测试

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/run_tests.gd
```

测试进程出现断言失败会以非零状态退出。脚本加载错误还需检查输出的 ERROR，不能单看命令退出状态。实际结果见 `TEST_RESULTS.md`。

## Android APK

`export_presets.cfg` 提供 Android / arm64-v8a 预设，采用非 Gradle 预构建模板。目标为较新的 64 位安卓手机，不包含 32 位 ABI。

电脑需 Godot 4.6.3 对应导出模板、该版本要求的 Android SDK Build Tools / Platform Tools，以及兼容 JDK。在 Godot 编辑器设置中填写 Java SDK、Android SDK 和调试签名路径。只有接受 Android SDK 许可后才安装受许可约束的组件。

```bash
mkdir -p build
godot --headless --path . --export-debug Android build/smooth-arena.apk
```

APK 使用开发调试签名，仅用于测试；正式发行需要自行管理正式签名。不要将 keystore、密码或 `export_credentials.cfg` 提交到仓库。同包名不同签名不能直接覆盖安装，先卸载旧版会删除其本地数据。

通过系统文件管理器打开自己构建的 APK 安装，按照 Android 的安装来源提示操作。构建成功不等于通过真机测试，实际状态见测试报告。

## 当前构建结果

已生成调试 APK（约 27 MiB），并通过 v2/v3 签名校验。最低 Android 7.0，CPU 为 arm64-v8a。APK 通过聊天附件交付；仓库只包含源码，不存放签名私钥。真机安装和画面尚未实测。

构建使用 Godot 4.6.3 的预构建 Android 模板（target SDK 36），OpenJDK 21 和 Build Tools 35.0.0；导出器显示 Build Tools 版本回退警告，但成功导出并验签。自行配置时建议遵循对应版本官方推荐工具链。
