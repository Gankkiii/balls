# Balls Auto Battle — v0.2

Godot **4.6.3 stable + GDScript**。光滑竞技场，五个角色随机选两个不同角色对战、自动技能、左侧冷却显示。Android ARM64 横屏。

## 打开与运行

导入 `project.godot`，F5运行。开局暂停，默认倍率1×；点击1×/2×/3×开始或继续，Pause暂停。**已恢复正常速度：1×/2×/3×分别为原来的1/2/3倍速。**所有移动、技能CD、充气、蹲蛋、引信都使用同一模拟时间。物理步长仍为1/120秒，不是将速度向量翻倍。

战斗一方HP归零结束，90模拟秒未结束则平局。点击 New 随机重新开始：重置双方生命、技能冷却、气量、蛋、计时和胜负，生成新随机开局，并按当前选中的倍率开始。暂停和战斗结束时都可重开。Replay 使用当前种子从头重开，同引擎/平台/代码下角色组合、初始速度、技能随机行为可复现。界面显示当前 Seed；角色不能重复。

## 角色规则

### 充气角色
- 被动普攻：气满100立即放气，移动加速，碰撞敌人造成36伤害，同目标接触伤害间隔0.35模拟秒。普通碰撞无伤害。
- 技能1 INFLATE：原地充气，每秒40气，CD6秒。充满直接进入放气。
- 技能2 ABSORB：免伤2.5秒，期间受到攻击按伤害×1.8充气，CD9秒。
- 放气每秒消耗25气，速度基于进入时基础速率提高2.5倍，放空结束。
- 外观直径随气量从原始1倍线性增大到满气2倍，放气时逐渐缩回原大小。沿用美术与碰撞独立的设计，物理碰撞圆半径保持24，不随美术膨胀。

### 炸弹母鸡
- 被动普攻：每1.7秒下小蛋；只有敌人碰到才触发0.8秒引信，爆炸按当时位置判定，半径70，伤害24。可以跑出范围躲掉。
- 技能1 PANIC RUN：随机乱跑1秒，每0.18秒重新选方向，速度1.8倍，CD5秒。
- 技能2 BIG EGG：原地蹲3秒，生成大蛋，落地1.5秒后爆炸，半径125、伤害62，CD10秒。
- 自己的爆炸只受20%伤害。自己不会触发小蛋引信，但在爆炸范围内仍会受伤。
- 外观用代码绘制头、冠、喙、身体、翅膀和脚；圆形碰撞体保持稳定，后续可换AnimatedSprite2D像素图。

### 泡泡鱼
- 自动每1.1秒吐1级泡泡，泡泡缓慢随机漂浮。1级碰到敌人直接消失、无伤害。
- 自己的泡泡接触融合，等级相加（1+1=2、2+2=4、1+2=3）；至少融合一次即等级≥2才有伤害，命中后消失。
- 等级无玩法上限；伤害暂定等级×8，外观/碰撞半径最大54，避免高等级覆盖整个场地，**尺寸限制不限制等级**。使用引擎64位整数存储。
- VACUUM BUBBLE：向敌人当前位置的方向直线发射吸附泡泡，飞行/吸附持续2.5模拟秒，吸引105范围内自己的泡泡并融合，之后恢复慢漂。CD7秒。
- EIGHT BUBBLES：向八方向发射1级小泡泡，0.8秒后结束高速移动，恢复慢漂。CD9秒。

### 触电羊
- 每次撞墙补30电，电库100。只要本体或羊毛附近有敌人就持续放电，**没有放电间隔**。
- 每模拟秒耗25电、造成20伤害，最后不足一帧的电量按比例结算；无目标不耗电，耗尽后停电，撞墙可补。
- WALL TURN：立即转向最近的墙移动，保持当前速度大小，CD5秒。
- DROP WOOL：在当前位置留下羊毛，场上同时只有一个，新羊毛替换旧羊毛，CD7秒。
- 羊毛与本体共享电库；任一处110范围内有敌人就能放电，重叠覆盖**只算一份伤害、一份耗电**。

### 磁铁蟹
- 每1秒掉铁钉。落地静止，无自动回收；踩到静止铁钉不掉血。
- 仅铁钉实际移动时造成伤害，暂定16、每枚命中间隔0.3秒；移动轨迹用线段检测避免高速穿过敌人漏判。
- MAGNET WALL：随机一面墙磁化，把自己的现有铁钉吸到墙边；各枚到墙后再飞回螃蟹，普通回收后消失。CD7秒。
- RETURN REPEL：准备将下一枚回到身边的铁钉向敌人当前方向弹飞，消耗一次准备状态。外飞0.8秒后落地静止，等待下一次磁墙。CD6秒；已准备时不反复刷新。

双方暂定120 HP。数值仅用于机制原型，尚未做平衡性验收。蛋最多32个，22秒后清理。

技能冷却就绪自动释放，不可打断的动作期间排队。两个技能同时就绪优先技能2，避免技能1反复执行导致技能2饿死。CD从施放开始计算。UI READY表示冷却完成，不代表能打断当前动作。

## 代码结构

- `Ball`：位置、速度、质量、半径、绘制和碰撞信号，唯一位置状态是Node2D.position。
- `Arena`：圆形连续碰撞检测、运动、场地与碰撞响应。
- `Fighter`：Ball子类，HP、CD、动作与临时站桩。
- `Puffer` / `Chicken` / `BubbleFish` / `ElectricSheep` / `MagnetCrab`：角色机制和外观，普通身体碰撞不伤血。
- `BombEgg`：触发、引信、范围伤害、显示。
- `Bubble` / `IronNail`：泡泡随机漂浮/融合与铁钉往返状态。
- `BattleArena`：Arena子类，统一固定步推进角色、物理、投射物、电量与胜负；种子控制选人和所有战斗随机源。
- `main.gd`：横屏主界面与左侧HUD、正常基准时间、倍率与重新开始。
- `baseline.gd` / `baseline.tscn`：保留原物理原型控制器作为历史归档；不再参与回归测试。控制器回归直接实例化当前 main.tscn。

站桩期间角色逆质量为0，作为不可推动的圆形障碍；动作结束恢复运动。游戏技能主动改变速度/质量约束，不要求战斗全过程动能守恒；无技能基础物理仍保持原守恒验收。

```bash

godot --headless --script tests/test_characters.gd
```

## Android

安装匹配的Godot导出模板及Android SDK/JDK，配置调试签名后：

```bash
godot --headless --export-debug Android build/balls-v0.2.apk
```

最低Android7.0，arm64-v8a。使用非Gradle预构建模板，配置见export_presets.cfg。项目不包含签名私钥。

GitHub Actions为**仅手动触发**。在Actions中运行`Test and build Android APK`，成功后下载`smooth-arena-android-apk`产物，解压得到APK。产物保留14天。工作流每次生成临时调试签名，因此不同次构建可能无法覆盖安装旧包，正式发行前应配置稳定签名；卸载旧包会清除本地数据。

当前状态和实际检查见TEST_RESULTS.md；构建和验签成功不代表已在真实手机上测试。
