# 美术团队配置（受保护）

本目录及项目 `.codex/agents/` 中的美术团队角色配置属于用户审阅的工作规则。未经用户明确同意，不得修改、删除、重写、覆盖或替换；如发现冲突或需要修改，先说明拟变更的文件与内容并等待用户确认。该标记是工作规则，不是访问控制或硬锁。

- `director.md`：美术总负责人完整职责。由用户直接指挥；每次美术任务开始前读取。
- `decisions.md`：已确认的全局设计决定。仅记录明确事实，需更改时先获得用户同意。
- `.codex/agents/`：七个团队岗位的独立配置；只有需要时由总负责人在用户授权的任务范围内调用。
- 每个角色单独维护 Markdown 设定文档，涉及该角色的任务开始前先读取；设定文档的位置由项目实际建立并记录，尚未建立时不能假装已存在。
- 给用户的评审网页、给点点的接入包是两项独立交付；具体内容由每轮用户指令决定。

## 新环境检查（不启动工作）

在含这些文件的仓库与分支中启动新 Codex 会话。请它只列出已读取的项目规则、美术负责人文档、可用自定义岗位及其名称；不派任务、不上传、不改文件。再确认角色配置实际被识别。不同云环境可能不支持同样的自定义角色加载，未验证前不能保证生效。60 分钟与禁止子岗位再派岗是指令约束，不是已验证的强制终止机制。

此仓库公开，仓库文件、分支和提交历史均可能被公开读取；不要写入密钥、用户私人截图或不具备公开许可的素材。
