# 给用户复制的初始化检查指令

以下内容仅用于检查，不会授权开始新一轮美术工作。请在包含这套文件的仓库和分支的新 Codex 会话中，由用户自行发送：

请先检查当前仓库及分支，读取根目录 AGENTS.md 和 art-team/director.md，检查 .codex/agents 下各角色配置是否被当前环境识别。请列出你实际读取的文件、可用角色和缺失或未识别的配置，并概括团队分工、角色设定文档规则、60 分钟限制及用户审批边界。只检查和汇报，不要创建子角色、开始任何美术任务、修改文件、上传或发布。

检查通过后，用户再自行下发具体的每轮任务；如果角色无法识别，请如实说明，不要声称已经生效。
