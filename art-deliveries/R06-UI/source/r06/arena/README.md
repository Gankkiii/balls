# R06 竞技场B方向细化

本轮只细化用户指定的B双侧角色卡方向，不再提供A–D选择；1600×900，不制作手机适配。主图`main.png`、信息副图`info.png`和各自可编辑SVG延用R05真实制作原件，未裁评审截图。世界700×600@450,180等比1:1。人工示例：鱼HP110/120，CD3.8/7.8；羊HP120/120，CD1.8/4.8、电量17.5/100。泡泡11个（10个1级、1个3级），等级没有玩法上限，羊毛共享电库。

`prototype.html`是纯UI示意，非游戏运行：暂停/继续、1×/2×/3×、声音会改变按钮状态；重看同seed与新局展示操作反馈，不模拟战斗或产生新随机状态；info和两侧i展开同一信息窗，×关闭。技能槽只读自动技能CD，不能点击施放。四页导航向宿主页发送`postMessage({type:'r06-nav',page:'arena'|'story'|'storage'|'hatch'})`；独立打开仅提示导航意图。切离竞技场的已有暂停/停音、返回不自动恢复规则没有被原型改写。

图标按钮均有title和aria-label；键盘焦点可见。核心技能文本、种子3103/时间5.3仅为人工示例，不声称同一真实轨迹可复演。`source/main.svg`和`source/info.svg`为内嵌原PNG的矢量制作源；R06根目录`build_arena_story.py`可从源重建图、HTML与索引。浏览器验证仅桌面Chromium原型点击，不等于Godot接入或真实设备验证。
