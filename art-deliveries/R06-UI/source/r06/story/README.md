# R06 主线D方向细化

本轮只细化用户指定的D档案+舞台方向，不再展示A–D候选，不制作手机适配。1600×900主图`main.png`与副图`detail.png`和SVG保持已有选定结构；地点A/B/C/D仅信息结构占位，不表示既定章节、关卡、解锁、进度、奖励或主线玩法。当前游戏主线仍为空白占位，原型中的目录、搜索、查看和返回属于待接入的展示交互。

`prototype.html`支持四条占位地点选择、搜索（无匹配明确反馈，清空可返回）、查看档案、×关闭或返回档案；两处?打开说明并可关闭；顶部‹返回竞技场；底部四页导航向宿主发送`postMessage({type:'r06-nav',page})`。每个主动按钮有落点。详情中的“待定”按钮明确禁用，不伪装为可执行关卡入口。地点切换只更新所选目录、标题与详情，不捏造四地故事内容。所有地点沿用同一占位舞台，仅说明信息归属。

`states/`为四条目主/详情状态PNG与可编辑SVG，HTML依赖这些文件，请复制整页目录。`source/main.svg`与`source/detail.svg`是内嵌项目角色PNG的原制作源；根目录`build_arena_story.py`可重建。此为纯UI示意非实际游戏导航；没有写本机保存、改变玩法或发出真实战斗指令。桌面Chromium点击验证不代表Godot或设备验证。
