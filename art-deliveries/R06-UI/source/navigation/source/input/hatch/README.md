状态目录可跳到每个业务状态；它不是方案选择。列表仅显示所选性别的10个亲本，20个体的完整数据与画像均可访问；列表内部滚动。详情包括当前/另两特性、当前2技能+n、余3技能待设计与六属性四列。取消不换亲本；对同一母亲再次点使用不重置已选并列技能。只有真正换母亲时才重置选择；非并列自动取最高，不提供无效二选一。
