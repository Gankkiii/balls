# R06 UI 接入交付

交给点点的资源与说明；**不是已接入游戏的UI**。游戏基线 `3dd29e881d43b0be53170696633a6c118cd7d077`，原评审基线 `Gankkiii/ball_art_review@54d8f8d48966e1e7af5e8261d44ad31ab9258e55`。

用户本轮已明确确认：竞技场B、仓库D完整属性默认常显、孵蛋B详细流程、主线D占位；四页统一仓库浅色顶部栏。A像素风、横屏、兔宽刀不变。继续暂停手机布局适配，本包只检查资源格式可导入；不宣称手机布局或真机通过。

1. 先读 [接入清单](docs/INTEGRATION.md) 和 [代码对应](docs/CODE_MAP.md)。
2. 看 `reference/final/` 四张完整目标参考；导航以本包为准。`reference/r06_original/` 20张旧子状态图保留原评审导航/调试字，只参考内容和流程，不能恢复旧导航或照抄调试按钮。
3. 可用文件在 `assets/`；[资源索引](ASSET_INDEX.md) 与 `metadata/` 给出尺寸、alpha、来源、切片、用途和状态。字体含完整中文Regular/Bold和许可。SVG/HTML/CSS制作源在 `source/`。
4. 仓库/孵蛋布局大量由Godot控件与StyleBox实现，不存在一张万能皮肤。完整参考图不是可直接替换页面的贴图，网页JS也不是Godot游戏逻辑。
5. 本包没有修改正式游戏代码。点点接入时应将实际需要的 `assets/` 文件复制到自己的运行资源目录并绑定控件；不要把整个制作源、fixture、浏览器原型或参考图作为运行依赖。

## 必须保留的行为

- 沿现代码的真实数据、孵蛋随机/保存规则与事件，不把人工fixture写进游戏。精灵Lv与技能强化+n独立。首次亲本未选择，已选后同会话返回保留。
- 不接入状态目录、重置示例、人工成功/失败、固定#21内存对象或网页评审控件。真实执行只能得到真实结果，保存失败不入仓。
- 主线仍占位；不新增关卡、奖励、体力、培养规则。竞技场技能仍自动，UI不能新增手动施法或改变物理。

## 完整性与边界

本包包含可用原件与源导出，不保证全部运行态齐备。缺四个角色的专属技能图标、部分按钮状态、独立UI音效/专用帧动画和主线正式内容；详见 [缺失与未定事项](docs/MISSING_AND_OPEN.md)。没有未答的本轮页面/导航选型问题；未定玩法保持原有占位。

[验收](qa/REPORT.md) 区分资源导入、原有游戏回归、未执行的R06游戏绑定与真机检查。`manifest.json`列包内文件字节与SHA256（不含其自身）；相邻ZIP及其SHA256另提供，ZIP不嵌套自身。

`source/r06/`是原评审制作源快照，里面“仅网页/不做包”等历史文字及R06检查记录不代表本轮指令或本包验收。当前范围以本README、接入清单和本轮用户回复为准。

解压后可运行`python3 tools/verify_manifest.py`核对全部包内文件。相邻`R06-UI.zip.sha256`核对压缩包本身；验证无需运行游戏。
