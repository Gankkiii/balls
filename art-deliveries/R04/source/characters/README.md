# R04 已选人物原件导出源

本目录只机械导出用户已认可的R04可编辑几何，不增加设计、不修改游戏。`original_r04/`保留对应评审制作函数；其中未使用的旧几何分支不是本包新增备选方案，不运行其评审网页生成入口。

依赖：Python 3、Pillow。原生PNG导出不需要浏览器、Godot、字体、SVG渲染器或网络。

从包根在新空目录复现：

```sh
python3 source/characters/export_characters.py --output /path/to/new-empty-directory
```

命令只写目标目录的`assets/characters/`和`metadata/characters.json`，不读取舞台PNG、GIF、截图或旧音频。它直接调用原始图形/姿势/物件函数；不通过裁图去掉背景。请不要覆盖已核验包。

实际产物：8角色共131个PNG/精灵条记录，含本体、眨眼帧、已存在的腿尾摆帧、按气量采样的姿势、独立物件及壳纹旋转。不是131个独立动作；hurt序列只有2种独立眼部画面，12格壳纹循环也只有2种独立纹理状态，均在metadata披露。

`hurt.png`和普通hurt序列仅为idle身体。鸡run提供同phase闭眼帧，蹲蛋另有纯身体闭眼姿势；充气球每气量采样有对应闭眼图；仙人掌花冠亮、乌鸦储羽状态也有保姿态闭眼图。受击应保持当前动作/phase/气量缩放/附属物，不把闭眼处理变成重置idle；尚无对应闭眼组合的未来姿势需点点只切眼层。免伤、保护、隐藏或不可受伤壳不触发普通HP下降眨眼。

`metadata/characters.json`明确哪些是可用独立纹理、哪些仅为状态采样、哪些动作未制作；世界位置演示、含鱼与8泡的组合图、鸡与世界蛋的组合帧、羊与世界羊毛/电弧舞台图均不作为人物精灵导出。场景/事件的实际绑定由点点负责，本包未修改任何游戏代码。

局部原点、身体参考半径和贴图缩放是呈现坐标，不生成或修改碰撞体。前4角色无已验证的游戏挂点；metadata区分源几何身体中心/交接建议与`runtime_origin_verified=false`。后4保留R04源声明的挂点，同样未宣称实机验证。脚底、眼睛、壳纹轴等应在点点实际接入时复核。
