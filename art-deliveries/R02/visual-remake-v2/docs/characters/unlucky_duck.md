# 倒霉鸭：本轮新制交付设定摘录

版本：`R02-remake-1`；用途：新视觉素材的角色事实与接入边界。**本轮重制，不是找回的旧R02角色原件。** 角色事实摘自用户已授权沿用的原合并册 `R02-A-characters-0.1`；本文件不新增角色背景、技能或数值，也不修改受保护团队配置。

## 已有角色事实

- 暖黄色身体、橙色嘴和脚、珊瑚帽、深色眼睛；沿A像素风。
- 无手持武器；雷云、落雷及避雷针是关联道具/表现，不把鸭改成持剑角色。
- 已有机制：碰撞转移雷云、雷云倒计时、落雷、避雷针。声音使用转移/倒计时/雷击，不套金属剑击声。
- 本轮用户确认制作对象是**鸭与锻造兔**，不是鸡。不得混入炸弹母鸡造型、蛋或爆炸机制。

## 原始依据与本轮技术规格分开

原合并册旧稿声明64×64导出、建议脚底(32,60)，并明确cast/impact不是完整动画；旧透明原帧未找到。该声明不能证明新素材已经游戏验证。

本轮人物岗约定的制作接口：96×96 RGBA帧、48逻辑像素×2 nearest；身体origin(48,56)、脚底anchor(48,80)；主朝右，左向用水平镜像。**具体动作/时长/帧数、透明边界与路径以同包人物manifest实测值为准。** 若manifest与本页冲突，先报告协调，不由接入者猜测。

## 游戏绑定与边界

`UnluckyDuck`现有字段：`cloud_holder`、`storm_left`、`rods`、`lightning_flash`、`strike_position`、`health`、`cd_one/cd_two`。`contact()`碰撞转移，`strike()`真实结算保护/伤害并重置周期。没有现成名为cast/impact的游戏技能状态，动作名称仅作视觉播放标签。

雷云实际归属与数字使用实时字段；保护与落雷跟真实结果。不能把概念影片固定7秒编排做现实定时器，不能改碰撞、避雷范围、伤害、冷却或随机结果。道具的外观尺寸不是新碰撞体。
