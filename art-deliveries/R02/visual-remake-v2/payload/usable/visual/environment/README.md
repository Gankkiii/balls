# R02 浅色竞技场独立素材（本轮重制）

这是一套新制作的可导入图形及同源 SVG，不是从历史评审整图裁出的图层，也不是找回的旧 R02 原件。没有图像输入、第三方贴图、字体或照片；新程序源位于交付 `source/build_environment_vfx.py`，SVG 均可独立编辑。

|文件|格式/尺寸|位置与用途|
|---|---|---|
|`arena_floor.png` / `.svg`|700×600；PNG RGBA，整张不透明|地板左上对应逻辑场地(0,0)，1100×780参考横屏中放(200,90)，按1:1显示。低对比平面纹样不是障碍|
|`arena_wood_frame.png` / `.svg`|720×620；透明PNG，内孔(10,10)宽700高600|放UI(190,80)，或其锚点(10,10)对准地板左上。外框至x910/y700，不侵左右状态面板和y706操作条。外框只作装饰，不加碰撞|
|`corner_inlay.png` / `.svg`|64×64；透明PNG|可选角饰，按90°旋转用于其余角。仅用于场外边界/装饰层，不应遮挡角色或作为可碰撞物|
|`screen_surround.png` / `.svg`|1100×780；PNG RGBA，整张不透明|全画面最底层，场地和左右状态面板是其上独立层。不是含UI/角色的合成背景|
|`manifest.json`|可读JSON|以上素材的尺寸、锚点、建议UI位置与边界|

建议层次：screen_surround → arena_floor → arena_wood_frame / 可选角饰 → 场上道具与角色 → 局部VFX → 实时UI。角色、道具、HUD和数字均未烘焙进上述背景。

采样使用nearest；按真实700×600模拟场地做等比映射，不能为适应画面改物理范围。横屏额外宽度优先给两侧安全留白；不要把地板非等比拉伸后仍宣称角色/碰撞视觉一致。左右状态面板和操作条由UI岗位交付，实际安全区/触控与真机仍需点点接入后测试。

`preview/environment_composition.png` 在交付预览区，仅将新地板与新边框合成供检查，不是独立层的替代品；它不应列入可导入场景素材。
