## 音画事件与规则

- 转云：`duck_cloud_transfer.wav`；只能真实碰撞转云播放，不把雷击后的云重置当成转云。
- 未保护落雷：`duck_lightning.wav`；必须服从真实strike结果，不写成固定7秒现实循环。保护效果没有新增独立音频，不擅自用刀击或伤害雷声补配。
- 锻造接触：`anvil_forge.wav`，跟小锤/铁砧接触帧走；不是每个绘制帧播放，也不是宽刀命中。
- 宽刀有效命中：`sword_wide_hit.wav`与第0帧同时反馈实际已发生接触。`sword_wide_swing.wav`仅用于有明确表现出手事件时，不能假造前摇或延后伤害。
- 云倒计时tick/final仍由真实模拟剩余时间阈值驱动，不能直接挂在cloud_idle的循环帧上。
- 真实事件先结算，效果只反映结果。不改伤害、射程、碰撞、随机、技能时序、保护半径或模拟步。特效环大小不是作用范围。
- 暂停冻结效果时间/音源头；恢复不补播历史事件。循环效果在状态结束时立即停止；单次结束释放。重开、切场、死亡/结算按表现生命周期清理队列，不残留。
- 1×/2×/3×效果帧时刻跟模拟时间；短音保持原音高/长度为现有提案，仍需接入后听审和混音验证。
