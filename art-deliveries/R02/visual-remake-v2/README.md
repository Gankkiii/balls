# R02 视觉重制交付包 v2

这是用户在确认旧R02视觉源件未找回后，授权重新制作的接入素材。**不是旧源包恢复件，也不是评审截图拆件。** 原 `R02-materials.zip` 和旧交付文件保留，本包是独立的新版本。

方向：A像素风；横屏左右状态区、浅色场地、极简常驻文字；倒霉鸭、锻造兔及道具全部新制；宽刀实际碰撞当帧命中，随后回收。不改变游戏玩法、物理、伤害或模拟时序。

## 给点点的入口

- `INTEGRATION_CHECKLIST.md`：准确路径、事件映射、Godot挂点及待实现代码清单。审阅状态见文首，不以文件存在冒称游戏验收通过。
- `ASSET_MANIFEST.json`：所有正式原件、制作源、预览和文档逐文件分类、尺寸、字节及SHA-256。只导入明确标记的资源，不整目录导入参考资料。
- `QA_REPORT.md`：实际验证范围及尚未验证项目。
- `SOURCES_AND_REBUILD.md`：制作来源、依赖及安全复现方法。
- `docs/characters/`：由已授权合并册摘分的鸭、兔事实及新素材接口，不新增角色设定。

## 完成边界

本轮指定的双角色、道具、横屏UI、场地和局部VFX都有实际独立视觉原件及制作源。**尚未接入真实游戏**，点点仍需替换代码绘制、绑定真实事件与动态数据、处理云/特效边缘避让、设备安全区和触控，并完整回归。原合并册中的历史“待选”或旧帧数不覆盖本轮已确认方向及实际重制manifest。

没有补制其余8个角色、全部游戏页面、字体二进制、音乐或新的避雷保护专用WAV；这些不属于本轮已选制作范围。7条原音效保留，保护分支的具体声策略仍由点点按真实事件与现有声音处理，不拿其他音效冒称新原件。

未进行实际手机安装、扬声器试听、人工听审或真实游戏动态音画验收。文件导入、源复现、静态组合与自动回归结果各自单独报告，不相互替代。

## 完整性与保留

从新的空目录解压后，在包根运行 `sha256sum -c SHA256SUMS.txt`。ZIP自身校验在仓库同名 `.sha256` 文件。每次重新打包都重新复制、解压、逐文件核验。

`.gdignore` 用于隔离交付目录，点点将选定原件复制到正式资源目录后再导入。不要删除隔离文件后让Godot将预览、制作源和旧候选一并当作游戏资源。没有修改游戏脚本、场景、玩法、物理或团队配置，没有删除旧交付与提交历史。
