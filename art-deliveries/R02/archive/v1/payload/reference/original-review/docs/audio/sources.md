# 来源与使用记录

周期 R02；声音版本 R02-A-audio-0.1；匹配角色设定 R02-A-characters-0.1。全部为本轮程序合成候选，没有下载第三方音频、使用录音采样或调用外部付费音频服务。铁砧以非整数泛音模拟金属；剑挥击以带通噪声及轻微扫频模拟气流；剑命中为短噪声与刃缘金属泛音；倒计时使用正弦提示，雷击使用噪声与短低频尾声。

合成源 `build_audio.py`、环境记录 `build_environment.json`、逐文件测量 `audio_metrics.json` 随素材交付。NumPy 是制作依赖，不是采样来源。随机种子2026110302；Python与NumPy版本以环境记录为准。复现须在新获授权周期内传入该周期真实截止时间与单独输出目录，例如 `python build_audio.py --output ./regenerated --deadline <获授权周期截止ISO时间>`；不得借改截止绕过已结束周期。本轮不在截止后再生成。命令会写出WAV和测量JSON，应避免覆盖已审核版本。
