# R02 · A方向 · 音效候选播放规则

音频版本：`R02-A-audio-0.1`；角色设定：`R02-A-characters-0.1`。短剑 `short_sword`、宽剑 `broad_sword` 都是待选候选。铁砧敲打是锻造独立工具声；剑挥击、剑命中分别使用气流切动声和短促刃缘金属声，不借用 R01 重锤撞击声。

时间线数字仅同步本轮概念演示，不能改写游戏碰撞、伤害或冷却逻辑。

## 拟定接入规则（尚未在游戏中实现）

- 格式：全部48kHz、16位PCM、单声道WAV，不循环。建议SFX总线初始-6dB，配置峰值限制器；单文件零削波不保证叠加零削波。短剑、宽剑各自独立比较，尚不选定武器。
- 优先级：落雷/有效命中 > 持云者改变/最后一秒 > 剑挥击 > 普通倒计时/锻打。重要事件发生时，正在播放的低优先级声可在10ms内压低6dB，120ms后用40ms恢复；这只是混音建议，不延迟命中声。
- 事件去重：用事件ID保证同一事件只播一次。挥击允许挥空，命中声必须等实际有效接触；不根据动画进入hit状态臆造伤害。锻打跟随明确接触帧，不按每次绘制触发。
- 重触发/并发：同一角色同一锻打/挥击新事件到达时，旧尾音20ms淡出后由新实例承接；命中及落雷保留真实不同事件，交总线保护处理，不能为了听感吞掉实际事件。试听页一次只播一条，这不是游戏并发策略。
- 取消：被取消的未发生挥击/命中不得排队播放；已开始的挥击可30ms淡出。已发生命中/落雷保留自然尾音，切场或重播时统一30ms淡出并清空待播事件。不能用锤打声补偿剑动作取消。
- 倒计时：从当前模拟剩余时间向下越过整数阈值才触发，1秒阈值用final；技能导致±2秒跳变时不要补播跨越的历史tick。暂停与恢复不重放已越过阈值；真实雷击可被技能立即触发，必须服从strike事件，不能写死7秒自循环。是否对正向加时后再次越界提示，建议允许一次新的越界提示并用事件序号区分。
- 暂停：暂停音源播放头及事件调度；恢复从原播放位置继续，不重触发。切出页面或设备音频会话中断时的实际恢复需平台测试。
- 倍速：短音保持原音高和长度，触发点跟随模拟时间；不使用简单变速提高音高。密集事件仍按语义优先级混音，不改变游戏结算。
- 静音：30ms淡出到0；继续推进事件状态且不积攒声音。恢复30ms淡入，只播放此后新事件，不补播静音期间历史事件。本轮没有持续循环声，因而没有需要重建的循环播放头。
- 单声道与可读性：可根据位置轻量声像，但倒计时与归属必须同时可视，不用左右声道作为唯一信息。

## 实际验证边界

已生成WAV并检查头信息、PCM峰值/RMS/削波；试听页提供浏览器原生播放控件，点击后播放并停止其他条目。没有人工听审、手机扬声器试听、Godot导入或真实战斗验证。样片音轨同样属于候选展示。
