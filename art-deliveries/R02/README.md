# R02 素材交接包：现存成果重建

交付对象：点点。包版本：`R02-existing-materials-1`。本轮只整理、核对与交付，未重新设计、未生成替代图、未修改游戏代码。

**本包不是失落完整源包的恢复件，也不是全部可直接接入的最终美术。** 当前可直接复制导入的是 7 条原始独立音效；角色透明帧、横屏 UI 拆件、场景、独立图标及特效原件没有找到。参考材料必须与可用素材分开使用。

## 本轮已确认

- 采用 A 像素风（暖色角色与深色轮廓）；不能以当前代码画面已经完整达到该风格为前提。
- 战斗界面采用极简信息方向；只考虑横屏，不制作或适配竖屏。
- 锻造兔使用 R02 宽剑/宽刀 `broad_sword`；不是细长剑或短剑，锻造小锤仅用于铁砧情景。
- 用户允许沿用合并设定册，只整理、不新增设定。参考原文中的“剑型待选”“UI 待选”等是历史状态，以本页与本轮指令为准；不改写历史原件或受保护规则。
- 用户在获知原始完整包无法找到后，明确要求重新整理一个 R02 整合包。此授权不代表已找回缺失源文件，不授权把预览截取成游戏原件。
