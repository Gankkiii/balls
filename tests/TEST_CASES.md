# T01–T24 回归验收目录

范围：共享基础物理与当前 v0.2 主场景，Godot 4.6.3。T01–T22 为自动用例，T23–T24 为人工验收，未实测不可标记通过。断言次数不等于独立用例数。

T01、T15–T19 已迁移到真实 main.tscn，不再执行旧 baseline 控制器。T02–T14、T20–T22 继续隔离验证无技能基础物理。旧控制器文件仅归档，不参与回归门禁。

## 固定容差（不得为掩盖退化擅自放宽）

逻辑像素位置误差 <0.002；速度向量误差 <0.002；孤立碰撞动能绝对误差 <0.01；动量向量误差 <0.002。边界容差0.01，重叠容差0.02。十分钟模拟动能相对误差 <0.001（0.1%）；高速测试 <0.0001。测试时间误差 <1e-9 秒。适用本用例的尺寸/速度范围，不代表任意尺度的通用精度保证。

## 回归门禁

每次开发修改后，必须运行完整自动化回归，通过后方可上库。失败先修复，禁止删除、跳过或放宽旧测试来制造通过。规则改变需用户确认并同步更新验收。人工项单独列出未验证，不并入自动通过数量。
