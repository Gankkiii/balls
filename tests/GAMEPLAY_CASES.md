# 玩法与孵蛋回归

本套测试由 `tests/test_characters.gd` 调用，运行真实 Godot 游戏代码，不使用替代模拟器。它们补充现有的物理、角色、全部角色组合和页面测试，不取代人工试玩、视觉或手机触摸验收。

## 孵蛋与仓库 H

- 不选择亲本、只选一个或亲本性别错误时不产生后代；实际点击孵蛋后恰好增加一只，且选中该精灵。
- 跨种亲本、母系种类与特性、性别、0级和后天值归零；六项先天值包含父母区间两端，覆盖相等、1和50。
- 两个技能的不同槽位、母亲最高技能、同级选择、第二技能不重复；第一技能以父母最高技能等级计算，临时突破和+10上限；第二技能+1至+9及当前临时权重。
- 连续孵蛋、仓库展示、重启后字段不变及继续孵蛋；写入失败时不添加新个体并提示失败。对缺失换行和损坏记录的检查在独立临时文件内执行。
- 每次运行使用独立的测试存档，不读取、修改或删除玩家的真实精灵。概率测试验证当前临时实现，并不表示概率已经最终确定。

## 战斗玩法 G

- 充气球：每个目标的放气撞击冷却独立，同一目标冷却内不重复伤害；吸收期间满气放气仍保留剩余免疫。
- 母鸡：被动下蛋、延迟引信及爆炸；泡泡鱼：八方向泡泡的方向和速度；螃蟹：四面磁墙及只吸自己的钉子。
- 鸭子：雷云倒计时、落雷重置和避雷针边界；锻造兔：自动锻造、速度恢复、淬火单次消耗和过期。
- 仙人掌：固定物理碰撞、持续接触和分离再接触、撒刺及换位置；乌龟：躲壳免疫、位置跟随、出壳、普通/旋转壳伤害与反弹。
- 乌鸦：稻草人数量、固定不动、攻击与实际反伤、羽毛回血；羊：墙壁充电上限、羊和羊毛不叠加伤害、转向速度最低140。
- 胜负与暂停：单方/双方归零、超时、结束冻结；新角色不同倍率和暂停下的模拟状态检查。

与 `tests/v04_cases.gd` 现有45种组合的单种子可复现/终局检查互相补充。用户体验、所有可能的交互与数值平衡不可能仅凭这组用例被保证；扩展新角色或机制时应继续检查边界和特殊组合。
